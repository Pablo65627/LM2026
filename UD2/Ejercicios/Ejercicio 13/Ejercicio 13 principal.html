Sistemas gestores de contenidos

Historia

Los primeros sistemas de gestión de contenido o sistemas de gestión de contenidos fueron desarrollados por organizaciones que publicaron una gran cantidad de contenido en Internet y necesitaban actualizaciones continuas como revistas en línea, periódicos y publicaciones corporativas.

En 1995, el sitio de noticias tecnológicas CNET publicó su sistema de gestión y publicación de documentos y creó una empresa llamada Vignette, pionera de sistemas de gestión de contenidos comerciales.

La evolución de Internet hacia los portales con más contenido y la alta participación de los usuarios directamente, a través de blogs y redes sociales, convirtió los gestores de contenidos en una herramienta esencial para internet, tanto para empresas como para instituciones y para personas.

Los wikis y sistemas de trabajo en grupo también son considerados CMS.

Actualmente hay sistemas desarrollados en software libre y software propietario. En ambos casos, es necesaria una implementación para adaptar el gestor de contenidos al esquema gráfico y las funcionalidades deseadas. Para algunos gestores hay muchos modelos disponibles que permiten una simple implementación de la parte estética por parte de un usuario sin conocimiento de diseño. Los paradigmas de este caso son WordPress y Joomla, gestores sobre los que hay una gran comunidad de desarrolladores de extensiones (módulos, complementos, etc.) y modelos.

Definición

Es una página web con algunas funciones de publicación. Tiene una interfaz administrativa que permite al administrador del sitio crear u organizar documentos diferentes.

El gestor de contenido es una aplicación informática utilizada para crear, editar, gestionar y publicar contenidos multimedia en varios formatos. El gestor de contenido genera páginas web dinámicas que interactúan con el servidor web para generar la página web a petición del usuario, con el formato predefinido y el contenido extraído de la base de datos del servidor.

Esto permite gestionar, bajo un formato estandarizado, la información del servidor, reduciendo el tamaño de las páginas para la descarga y reduciendo el coste de gestión del portal respecto de un sitio web estático en el que cada cambio de diseño debe realizarse en todas las páginas web, al igual que cada vez que añades contenido debes hacer una nueva página HTML y cargarla en el servidor web.

Gestión de contenido

Todo el Sistema de gestión de contenido realiza el siguiente proceso de gestión:

Creación de información. Es el proceso por el cual el usuario genera nueva información para poner a la disposición del público. Puede generar información como texto, gráficos, imágenes, etc.

Presentación de la información

  • Publicación de la información
  • Mantenimiento de la información. Es la actualización en la que puedes editar o eliminar cierto contenido.

Otras consideraciones iniciales

Entendido como un sistema de soporte para la gestión de contenidos; ya que, en realidad, son estrategias de comunicación que realmente llevan a la gestión de contenidos y publicidad efectivamente; Los sistemas informáticos pueden proporcionar, como mucho, las herramientas necesarias para la publicación en línea, o incluir servicios de apoyo a la decisión para la gestión de contenidos.

El gestor de contenidos generalmente se aplica para referirse a los sistemas de publicación y se pueden subestimar las funcionalidades de soporte y mantenimiento, en detrimento de las funcionalidades relacionadas con la optimización de los tiempos de publicación. Es necesaria la correcta implantación del sistema, según las necesidades del cliente y es necesario comprender el proyecto de un portal web dentro de un proyecto de comunicación estructurado y bien planeado.

La elección de la plataforma correcta será vital para conseguir los objetivos del cliente, ya que existen particularidades diferenciales tanto en su adaptabilidad a esquemas gráficos como en la posible integración de características y extensiones adicionales.

El posicionamiento en buscadores está relacionado con el volumen de contenido de un portal y con la forma en que se presenta. Es importante tener en cuenta esta estructura del portal para garantizar un correcto posicionamiento orgánico.

Operación

Un sistema de gestión de contenido siempre funciona en el servidor web donde está hospedado el portal. El acceso al gestor generalmente se hace a través del navegador web y es necesario el uso de FTP para cargar contenido.

Cuando un usuario accede a un URL, esa llamada se ejecuta en el servidor, se selecciona el esquema gráfico y se ingresan los datos correspondientes de la base de datos. La página es generada de forma dinámica para ese usuario, el código HTML final se genera en esa llamada. Normalmente, varios formatos de contenido de presentación están predefinidos en el gestor para darle flexibilidad al crear nuevas secciones e información.

Gestión de usuarios

Dependiendo de la plataforma elegida, se pueden escoger diferentes niveles de acceso para los usuarios; pasando del administrador del portal al usuario sin permiso de edición o creador de contenido. Dependiendo de la aplicación, puede haber varios permisos intermedios que permiten la edición de contenidos, el seguimiento y la republicación del contenido de otros usuarios, etc.

El sistema de gestión de contenidos controla y ayuda a gestionar cada etapa de este proceso, incluyendo las tareas técnicas de publicación de los documentos en uno o más sitios. En muchos sitios con estos sistemas, una sola persona desempeña el papel de creador y editor, como por ejemplo en los blogs personales.
